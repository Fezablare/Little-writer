# Little Writer

A kids’ learning app with two tabs. Open `index.html` in a browser (double-click the file, or drag it into Chrome).

## Writing

A 12-week English writing programme. Each week is one story:

1. Lesson — what the rule is and why
2. Read the week’s short story and fill the spelling gaps (warm-up → practice → boss)
3. Practise the skill (build, choose, spot, or expand) with the same mastery layers
4. Deepen (fix, arrange, or expand)
5. Free write with a soft coach — compare to a strong example, tick a short checklist, optional tip retry

There is also a 100-sentence unscramble path under Writing.

## Maths

A separate Times tables path: see equal groups / arrays, skip-count the pattern, then know the fact. Starts with 2s, 5s and 10s. No timers in this version.

Progress for both tabs stays in the browser on this device.
